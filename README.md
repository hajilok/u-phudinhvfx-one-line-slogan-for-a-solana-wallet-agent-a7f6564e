# One-Line Slogan for a Solana Wallet Agent

Deterministic `program/v1` entry for the [make.fun](https://make.fun/r/41fw6r6c) competition **One-Line Slogan for a Solana Wallet Agent** (`u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e`).

## Usage

Runs on Node.js 22.18+ with zero external dependencies and writes the single-line UTF-8 slogan (<= 20 words, 1–140 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local testing):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
